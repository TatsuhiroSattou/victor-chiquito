## Descripción breve
Portafolio personal desarrollado con HTML y CSS. Presenta información sobre mi
perfil como ethical hacker, mis habilidades técnicas, una sección de proyectos
con espacio para mostrar write-ups de vulnerabilidades reportadas y reconocidas
por organizaciones como Lenovo, Motorola, NASA y Harvard, y un formulario de
contacto.

## Tecnologías utilizadas
- HTML5 (etiquetas semánticas: header, nav, main, section, footer, article)
- CSS3 (Flexbox, variables CSS con `:root`, pseudoclase `:hover`)
- Google Fonts (IBM Plex Mono, Inter)
- Git y GitHub

## Instrucciones para visualizar el proyecto
1. Clona este repositorio:
   ```
   git clone https://github.com/TatsuhiroSattou/victor-chiquito.git
   ```
2. Abre el archivo `index.html` en tu navegador (doble clic o "Open with Live Server"
   en VS Code).
3. No requiere instalación de dependencias adicionales.
